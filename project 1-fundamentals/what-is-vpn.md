
## 💡 What is a VPN?


     A VPN (Virtual Private Network) creates a secure encrypted tunnel between your device and a remote network.



## Why Companies Use VPN ?

 Remote workers need access to:

→ Internal file servers and databases

→ Company intranet and applications

→ Network printers and email servers

These are not exposed to internet directly VPN provides the secure encrypted bridge



## What VPN Does?

1. ENCRYPTS traffic - data scrambled in tunnel
 
2. AUTHENTICATES user - proves identity
 
3. CREATES virtual network interface on PC
  
4. ROUTES company traffic through tunnel



## Without vs With VPN

Without VPN:

Your PC → Internet → Company Server (unencrypted)

With VPN:

Your PC → Encrypted Tunnel → VPN Server → Company LAN




## Key VPN Terms


| Term           | Description                                  |
| -------------- | -------------------------------------------- |
| VPN Client     | Software on PC (AnyConnect, GlobalProtect)   |
| VPN Server     | Company gateway accepting connections        |
| Tunnel         | The encrypted connection                     |
| Authentication | Proving who you are                          |
| Encryption     | Scrambling data so only auth parties read it |
| Split Tunnel   | Only company traffic through VPN             |
| Full Tunnel    | ALL traffic through VPN                      |
| VPN Adapter    | Virtual NIC created by VPN software          |
